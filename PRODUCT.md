# ZEUS Finance — Product Context

## Product

ZEUS Finance is a personal finance web application for recording and monitoring expenses, debts, and savings goals.

## Platform

Responsive web application built with React and TypeScript.

## Users

People who want a simple view of their personal finances without the complexity of a full accounting system.

## Primary jobs

1. See monthly spending at a glance.
2. Understand total registered debt.
3. Track money reserved toward goals.
4. Add and remove financial records quickly.
5. Use the product comfortably on desktop and mobile.

## Product principles

- Calm by default.
- Financial numbers should be the easiest content to scan.
- One clear primary action in each form.
- Use plain Portuguese labels.
- Do not bury core tasks behind decorative UI.
- Trust comes from clarity, legibility, and predictable interactions.
- The visual system should feel like a real financial product, not a generic AI-generated dashboard.

## Constraints

- Preserve the current functional flows and API behavior.
- Keep the existing dark visual identity.
- Avoid decorative motion.
- Maintain responsive behavior and keyboard accessibility.
